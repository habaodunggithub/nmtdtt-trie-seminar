# Trie — Cây tiền tố

Bộ slide seminar Nhập môn tư duy thuật toán, gồm 63 trang tiếng Việt và các ví dụ tương tác trên cây Trie.

## Chạy bộ slide

Cần Node.js 22 trở lên.

```bash
cd slidev
npm ci
npm run dev
```

Mở http://localhost:3030. Dùng phím mũi tên để chuyển trang, `p` để mở chế độ thuyết trình. Bấm chấm nhỏ ở góc dưới phải sơ đồ để chạy/dừng ví dụ.

## Kiểm tra và build

```bash
cd slidev
npm run test:demo
npm run build
```

Bản cập nhật tương tác nằm trong [`slidev/`](slidev/). Xem [hướng dẫn chi tiết](slidev/README.md) và [nội dung gốc](NMTDTT-Nội-Dung-Slide-Trie.md).

Các tệp PDF/PPTX trong thư mục gốc là bản xuất có sẵn, không tự đồng bộ với mã nguồn Slidev.
